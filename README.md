## 🧑‍💻 About Me

I'm a Computer Science graduate and Software Developer passionate about building intelligent applications and scalable software systems.

My interests lie at the intersection of **Generative AI, Agentic AI and Software Engineering** — turning modern AI capabilities into practical, reliable applications.

- 🤖 Exploring **Generative AI, LLMs and Agentic AI architectures**.
- 🧠 Working with **LLM Fine-Tuning, LoRA, QLoRA and PEFT**.
- 🔍 Building knowledge-based applications using **RAG, embeddings and vector databases**.
- 🔗 Exploring **Model Context Protocol (MCP)** and AI tool integrations.
- 🕸️ Designing multi-agent workflows using **LangGraph and LangChain**.
- ⚙️ Building backend services and APIs with **Java, Spring Boot, Python and FastAPI**.
- 🌐 Developing modern web applications using **React, Next.js and Node.js**.
- 🏗️ Learning distributed systems, microservices, system design and cloud infrastructure.
